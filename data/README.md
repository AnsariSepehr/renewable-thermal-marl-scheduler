# data/

This folder is **git-ignored** (except this file). Everything in it is either downloaded or regenerated.

| Item | How you get it | Needed for |
|---|---|---|
| `pvgis_cache/*.csv` | Created automatically on first run by `src/solar_data.py` (free PVGIS API, no key). Needs internet once; falls back to a synthetic solar curve per site, with a warning, if PVGIS is unreachable. | Solar generation per data center |
| `pai_task_table.csv` | **Optional.** From the Alibaba Cluster Trace GPU-v2020 (Kaggle: `derrickmwiti/cluster-trace-gpu-v2020`). Put the file in this folder. | Real task sizes |
| `workflows_1000.pkl` | Generated by `python scripts/generate_workflows.py` (or notebook Phase 2). | Every training / evaluation run |

Without `pai_task_table.csv` the generator uses a log-normal task-size fallback and says so when it runs. The results in `results/` were produced with the real trace; a run without it will be statistically similar but not numerically identical.

The Alibaba trace is not redistributed here -- please obtain it from its original source and follow its terms of use.
